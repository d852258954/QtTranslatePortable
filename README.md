# QtTranslatePortable — 离线屏幕翻译工具（免安装便携版）

完全离线运行的 Windows 屏幕翻译工具：框选屏幕任意区域 → OCR 识别 → 神经网络翻译 → 悬浮气泡展示。
内置全部模型与运行时，**不需要联网、不需要安装、不上传任何数据**。

## 下载

前往 [Releases](../../releases) 页面下载最新 `QtTranslatePortable_vX.X_win64.zip`，
解压到任意目录后双击 `QtTranslate.exe` 即可（首次启动加载模型约十几秒）。

> 包体积约 1.2GB：包含 PP-OCRv6 识别模型、HY-MT1.5 翻译模型、llama.cpp 推理引擎与 Qt 运行时。

## 功能

- **框选翻译**（Ctrl+Alt+D）：支持多显示器、混合 DPI 缩放，每个屏幕均可框选
- **剪贴板翻译**（Ctrl+Alt+V）、**输入翻译**（Ctrl+Alt+M）
- **划词翻译**：拖选/双击选词自动翻译
- 悬浮气泡：跟随选区位置、宽度自适应，复制 / 固定 / Esc 关闭
- OCR 优化：DBNet unclip 修正、超宽行空白带切分、智能拼接
- 翻译服务自愈：llama-server 异常退出自动重启
- 托盘菜单：框选翻译 / 剪贴板翻译 / 划词开关 / 语言方向 / 开机自启动 / 退出
- 双击托盘图标打开主窗口（历史记录 / 设置面板：主题、字号、原文对照、快捷键等）
